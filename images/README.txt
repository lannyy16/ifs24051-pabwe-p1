GANTI GAMBAR DI FOLDER INI

Gunakan nama file berikut agar HTML langsung membaca gambar:
- Shawshank.png  = cover film The Shawshank Redemption (72x107)
- Godfather.png  = cover film The Godfather (72x107)
- DarkKnight.jpeg = cover film The Dark Knight (72x107)
- profil.png     = foto profil blog (32x32)
- Docker.png     = cover blog Docker/NGINX
- abdul.png      = foto CV (200x200)

Jika ingin memakai gambar sendiri, cukup ganti file gambarnya dengan nama yang sama.
Tidak perlu mengubah kode HTML.
